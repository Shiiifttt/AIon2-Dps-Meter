AION 2 DPS METER - SETUP
========================

1) Install Npcap (one time only)
   - Download it from the official site: https://npcap.com/#download
     (click the "Npcap 1.xx installer for Windows" link)
   - Run the installer. On the options screen, make sure this box is TICKED:
       [x] Install Npcap in WinPcap API-compatible Mode
   - Leave everything else as it is and click through to finish.

2) Unzip this folder anywhere you like (for example your Desktop).
   Keep all the files together - don't move the .exe out on its own.

3) Double-click  AionDpsMeter.UI.exe
   - Windows may show a blue "Windows protected your PC" box because the
     program isn't from a known publisher. Click "More info", then "Run anyway".
   - Start Aion 2 (before or after the meter, either is fine).
     The meter starts showing damage once you're in game and fighting.

If nothing shows up after a few fights:
   - Close the meter, right-click AionDpsMeter.UI.exe and choose
     "Run as administrator".
   - Still nothing? Send the newest file from the "Logs" folder (it appears
     next to the .exe) to whoever gave you this.

Good to know
   - Everything stays on your PC. The only internet use is downloading skill
     icons from the game's own image server.
   - The meter never updates or checks for updates by itself. To update, open
     Settings (gear icon) > Updates > "Check now". If a new version is out,
     a window shows what's new: click "Update Now" to install it (the meter
     restarts), or close the window to stay on your current version.
     Updates are checked for a digital signature, so only genuine releases install.
   - To uninstall: delete the folder. To remove Npcap too:
     Settings > Apps > Installed apps > Npcap > Uninstall.
